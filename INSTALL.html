METHOD 1 — NETLIFY DROP (Easiest · 3 minutes · Free)

🌐 Netlify Drop RECOMMENDED
  1. On your computer, go to netlify.com/drop
  2. Drag the entire skywatch folder (not just files — the whole folder) onto the page
  3. Wait ~10 seconds — Netlify gives you a free URL like:
    https://skywatch-abc123.netlify.app
  4. Copy that URL and open it on your iPhone in Safari
  5. In Safari, tap the Share ⎋ button (bottom centre)
  6. Scroll down and tap "Add to Home Screen"
  7. Tap "Add"
  8. ✅ SkyWatch icon appears on your home screen — opens full screen like a real app!
⚠️ Must use Safari on iPhone/iPad — Chrome does not support "Add to Home Screen" properly on iOS.

METHOD 2 — GITHUB PAGES (Free · Permanent URL)

🐙 GitHub Pages FREE FOREVER
  1. Create a free account at github.com
  2. Click New Repository — name it skywatch — set to Public
  3. Click "uploading an existing file"
  4. Drag ALL files from the skywatch folder (index.html, sw.js, manifest.json, all PNGs)
  5. Click Commit changes
  6. Go to Settings → Pages → Source → Deploy from branch → main
  7. Click Save — your URL will be:
    https://YOUR-USERNAME.github.io/skywatch
  8. Open that URL in Safari on iPhone → Share ⎋ → Add to Home Screen

METHOD 3 — SEND TO FRIENDS (Share the URL)

📤 Share with Others
  1. Once hosted (Netlify or GitHub), you get a public URL
  2. Share that URL via WhatsApp, iMessage, Email
  3. Friend opens it in Safari
  4. Share ⎋ → Add to Home Screen → Add
  5. ✅ Everyone gets the same app — each person uses their own GPS location

ABOUT LIVE FLIGHT DATA

  1. ✅ Data from OpenSky Network — free, no API key needed
  2. ✅ Real ADS-B transponder data from actual aircraft
  3. ✅ Updates every 15 seconds automatically
  4. ⚠️ If flights don't load: OpenSky free tier allows 1 request/10 sec
  5. ⚠️ If blank: tap ↺ REFRESH button — OpenSky may be rate limiting
  6. 📡 Over busy airspace (near airports) you'll see 10–30+ aircraft
  7. 🌤️ Rural areas may show 0–3 aircraft — that's real data!

TROUBLESHOOTING

  1. ❓ No flights showing: Tap Refresh. OpenSky rate-limits anonymous users.
  2. ❓ GPS not working: iOS Settings → Safari → Location → Allow
  3. ❓ "Add to Home Screen" missing: Must use Safari, not Chrome/Firefox
  4. ❓ App opens in browser: Delete and re-add from Home Screen
  5. ❓ Demo mode showing: You tapped "Try Demo" — reload page and tap "Use My Location"
