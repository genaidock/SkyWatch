🇮🇳 INDIA COVERAGE — API KEYS
India has very few ADS-B ground receivers. Use one of these APIs which get data from airline systems instead — they work everywhere in India.

Priority order: AirLabs → AviationStack → Airplanes.live → ADS-B.lol → ADS-B.fi
📡 API SOURCES — ENABLE / DISABLE
Airplanes.live
Free · No key · Crowdsourced ADS-B
ADS-B.lol
Free · Location-based · Sparse India
ADS-B.fi
Free · Alternative ADS-B source
AirLabs.co
Requires API key · Best for India
AviationStack
Requires API key · Airport-based query
